On these pages, the complete analysis accompanying the manuscript can be found. Each part corresponds to a subsection of the Results section in the manuscript, which is divided into 1. *In situ* experiment and 2. MTC model.

All custom modules developed for the manuscript can be found [here](modules.qmd). 

## 1.1. Reliability experiments

*Section: 'Reliability of experimental force measurements'*

The page [reliability experiments](in-situ/reliability-experiments.qmd) contains the analysis regarding the reliability of the experiments. It includes the computation of several metrics used to assess the repeatability of experimental measurements.

## 1.2. MTC property estimation

*Section: 'MTC property estimation'*

The page [MTC property estimation](in-situ/mtc-properties.qmd) contains the analysis of the estimated MTC properties.  

## 1.3 Experimental SSCs

*Section: 'Stretch-shortening cycles'*

The page [experimental SSCs](in-situ/exp-ssc-ampo.qmd) contains the evaluation of measured AMPO for the stretch-shortening cycles that were experimentally tested.

## 2.1 Measurements against predictions

*Section: 'Evaluation of measured versus predicted maximally attainable AMPO'*

The page [measurements against predictions](mtc-model/measured-vs-predicted.qmd) compares experimentally measured AMPO with model predictions for the same MTC length and stimulation trajectories.

## 2.2 Imposed SSCs with constant MTC shortening/lengthening velocity

*Section: 'Imposed stretch-shortening cycles — constant MTC shortening/lengthening velocity'*

The page [imposed SSCs with constant MTC shortening/lengthening velocity](mtc-model/ssc-cv.qmd) contains the predictions of the influence of cycle frequency, FTS and MTC length excursion on the maximally attainable AMPO for stretch-shortening cycles with different constant MTC velocity during shortening and lengthening.

## 2.3. Imposed SSCs with optimal MTC shortening/lengthening velocity

*Section: 'Imposed stretch-shortening cycles — optimal MTC shortening/lengthening velocity'*

The page [imposed SSCs with optimal MTC shortening/lengthening velocity](mtc-model/ssc-oc.qmd) contains the predictions of the influence of cycle frequency, FTS and MTC length excursion on the maximally attainable AMPO in stretch–shortening cycles, where MTC velocities are optimised to maximise AMPO.
